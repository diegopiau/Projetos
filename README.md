# Projetos
Repositório para salvar alguns projetos pessoais e profissionais

## Setup do Claude Code (Vibe Coding Toolkit)

Este repositório usa o método do
[Vibe Coding Toolkit](https://github.com/soumatheusgomes/vibe-coding-toolkit)
pra trabalhar com o Claude Code: `CLAUDE.md` (instruções de projeto), regras de
orquestração de subagentes e sistema de memória em `.claude/`. Guia completo de
como usar cada ferramenta do toolkit: [`docs/vibe-coding-toolkit-guia.md`](docs/vibe-coding-toolkit-guia.md).
